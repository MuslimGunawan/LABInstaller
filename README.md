## Memulai Cepat (Untuk Admin Lab)
Cukup jalankan satu berkas di root:
```cmd
Start.bat
```
Program akan meminta elevasi Administrator otomatis, memeriksa kelayakan sistem (pre-flight), dan membuka antarmuka grafis (GUI) berbahasa Indonesia.
